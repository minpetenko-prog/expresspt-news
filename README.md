# Парсер новостей для @ExpressPT

Раз в 30 минут проверяет 16 португальских изданий, отбирает новости по темам канала и присылает их в закрытый Telegram-канал или чат.

Есть два режима:

- **С ключом Claude API.** Бот сам отбирает новости и присылает **готовые посты** в стиле @ExpressPT. Эмодзи в начале поста — это ссылка на источник. Под постом стоит кнопка с названием издания. Остаётся переслать пост в канал.
- **Без ключа.** Бот присылает подборку заголовков со ссылками, отфильтрованную по ключевым словам. Нужную новость вставляешь в проект Claude с инструкциями из `INSTRUCTIONS.md` и получаешь готовый пост.

Работает бесплатно на GitHub Actions, сервер не нужен.

## Файлы, которые можно менять

| Файл | Что в нём |
|---|---|
| `topics.yaml` | Темы канала, ключевые слова и что пропускать. **Сейчас там черновик — замени на свой список.** |
| `INSTRUCTIONS.md` | Как писать посты: тон, структура, эмодзи, оформление цифр. Его же можно вставить в проект Claude. |
| `config.yaml` | Источники, лимит постов за запуск, подпись, модели. |

## Установка (≈15 минут)

### 1. Бот и канал в Telegram
1. Создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и сохрани токен.
2. Создай закрытый канал (или группу) для черновиков и добавь бота администратором с правом публикации.
3. Узнай id канала. Опубликуй в канале любое сообщение и открой `https://api.telegram.org/bot<ТОКЕН>/getUpdates`. В ответе найди `"chat":{"id":-100…}` — это и есть id.

### 2. Репозиторий на GitHub
1. Создай репозиторий и загрузи туда содержимое этого архива. Папка `.github` тоже нужна, она скрытая.
   - **Публичный репозиторий:** минуты Actions безлимитные. Секреты при этом никому не видны, в репозитории только код и список уже показанных ссылок.
   - **Приватный репозиторий:** бесплатно 2000 минут в месяц. Запуск раз в 30 минут — это около 1500 минут, впритык. Если лимит не хватает, в `.github/workflows/news.yml` поменяй расписание на `7 * * * *` (раз в час).
2. Открой **Settings → Secrets and variables → Actions → New repository secret** и добавь:
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   - `TELEGRAM_CHAT_ID` — id канала, например `-1001234567890`;
   - `ANTHROPIC_API_KEY` — ключ с [platform.claude.com](https://platform.claude.com). Необязательно: без него будет режим подборки.
3. Открой **Actions → ExpressPT news → Run workflow**.

При первом запуске бот пришлёт сообщение «Парсер запущен» и сколько источников работает. Все текущие новости он отметит как прочитанные, чтобы не завалить чат. Дальше будут приходить только новые.

## Сколько стоит режим с Claude

Отбор делает Claude Haiku 4.5 ($1 / $5 за млн токенов), посты пишет Claude Sonnet 5.5 ($2 / $10). При 10–15 постах в день выходит примерно **$10–15 в месяц**.

Лимит — `max_posts_per_run: 5` в `config.yaml`. Новости, которые не влезли в лимит, переносятся на следующий запуск.

## Ограничения источников

- **Público, Expresso, SIC.** Часть статей платная, или сайт закрыт от ботов. Тогда пост пишется только по заголовку и анонсу и выходит коротким. На кнопке под постом в этом случае стоит пометка «только анонс».
- **Lusa и tempo.pt** не отдают RSS, их новости берутся со страниц сайтов.
- Некоторые сайты могут блокировать серверы GitHub. Если источник не отвечает 6 запусков подряд (около 3 часов), бот напишет об этом в чат.
- GitHub иногда запускает задачи по расписанию с задержкой 5–15 минут.

## Ручной режим: проект Claude

1. В claude.ai создай проект «ExpressPT».
2. Скопируй весь текст `INSTRUCTIONS.md` в инструкции проекта.
3. Присылай в чат проекта ссылку или текст новости, в ответ получишь готовый пост.

## Запуск на своём компьютере

```bash
pip install -r requirements.txt
python -m newsbot --dry-run            # показать в консоли, что бы ушло, ничего не отправляя
python -m newsbot --dry-run --url https://eco.sapo.pt/...   # переписать одну статью (нужен ANTHROPIC_API_KEY)
python -m pytest -q                    # тесты
```
